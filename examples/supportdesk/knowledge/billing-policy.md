# Harbor API — billing support

Example product policy, version 1. This is fictional demonstration material.

Refunds and service credits require review by the billing team. A support draft
must not approve a refund, promise a specific amount, or promise a processing date.
For a refund request, collect the invoice reference, transaction date and a short
description of the issue, then create a billing handoff for a human reviewer.

A pending card authorization is different from a settled charge. A customer's
message alone does not establish whether two charges settled. Ask for invoice
references and transaction dates; do not diagnose duplicate billing from a claim
alone. Never request the full card number, CVV, banking password or security code.

Support can explain this review process and identify missing information. This
workspace has no live billing integration and cannot confirm payment status,
change a subscription or issue money. Do not imply those actions happened.
